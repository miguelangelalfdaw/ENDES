# Actividad 1.4: Conceptos Básicos de Sistemas y Software

## 1. ¿Qué es un programa informático?

Es un conjunto secuencial de **instrucciones, órdenes o algoritmos escritos en un lenguaje de programación**. Su propósito es indicar al hardware de un ordenador qué tareas debe realizar, cómo debe procesar la información y qué resultados debe devolver.

<br>

## 2. En qué parte del hardware se ejecuta un programa informático

Se ejecuta principalmente en el **procesador (CPU)**, que es el encargado de **interpretar y procesar las instrucciones.** Para ello, hace uso de la **memoria principal (RAM)**, donde se cargan de forma temporal tanto las instrucciones del programa como los datos que este necesita manipular en tiempo real.

<br>

## 3. Qué es un proceso

Es un **programa en ejecución**; una instancia activa a la que se le han asignado recursos del sistema (como tiempo de CPU, espacio en memoria RAM, descriptores de ficheros y privilegios) para que pueda llevar a cabo su trabajo de manera independiente.

<br>

## 4. Qué es el software de sistemas o de base. Indica tres que suelas utilizar

Es el conjunto de programas fundamentales que **administran y controlan el hardware del ordenador**, dándonos una plataforma de soporte sobre la cual podemos ejecutar las aplicaciones de usuario.

* **Windows 11:** Sistema operativo principal para la gestión de equipos de escritorio.
* **Ubuntu Linux:** Sistema operativo basado en Linux, muy utilizado en servidores y entornos de desarrollo.
* **Docker Engine:** Software de virtualización a nivel de sistema operativo que gestiona contenedores.

<br>

## 5. Qué es una aplicación. Indica tres que suelas utilizar

Es un tipo de software diseñado específicamente para **facilitar al usuario la realización de tareas concretas** (laborales, de ocio, educativas o de gestión), aprovechando los servicios del software de sistemas.

* **Visual Studio Code:** Entorno de desarrollo integrado (IDE) para escribir y depurar código.
* **Google Chrome:** Navegador web para acceder a recursos de internet y plataformas online.
* **Discord:** Aplicación de comunicación por voz, texto y vídeo para la colaboración en comunidad.

<br>

## 6. Qué es un controlador hardware

Es un programa informático especializado que actúa como **puente entre el sistema operativo y un dispositivo físico** (como la tarjeta gráfica, la impresora o el teclado). Su función es traducir las órdenes generales del sistema operativo a un lenguaje específico que el componente hardware pueda comprender y ejecutar.
